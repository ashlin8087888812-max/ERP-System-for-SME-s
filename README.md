Gestace
Gestace is a full-stack SaaS platform built for modern business operations, ERP integration, and real-time collaboration. The project combines a Flutter frontend with a FastAPI backend and integrates with PostgreSQL, Redis, Celery, and Odoo to deliver a scalable business system.

Overview
Gestace is designed to provide:

secure authentication and user management
ERP-backed business data workflows
communication and collaboration features
scalable backend services
modular architecture for future product growth
Architecture
The system is built around a modular application design:

Flutter client for user interaction
FastAPI service for API and WebSocket endpoints
PostgreSQL for persistent data storage
Redis for real-time communication and task handling
Celery for background processing
Odoo for ERP integration
Key Features
Multi-platform Flutter client
FastAPI REST API
Real-time messaging
Odoo integration
Multi-tenant app structure
Admin management tools
Background task processing
Monitoring and logging support
Technology Stack
Flutter / Dart
Python / FastAPI
PostgreSQL
Redis

Project Status
This project is currently in active development and is structured as a production-ready foundation for a SaaS business platform.
